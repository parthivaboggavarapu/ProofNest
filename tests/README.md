# ProofNest tests

Test code is not implemented in the blueprint phase.

Planned suites:

| Path | Purpose | Owner |
| --- | --- | --- |
| `tests/backend/` | Service, model, auth, and isolation tests | Backend + Database + AI |
| `tests/frontend/` | Component and form tests | Frontend Lead + Frontend Developer |
| `tests/integration/` | API + MongoDB + storage adapter tests | Backend Developer |
| `tests/e2e/` | Browser journeys | Frontend + Project Lead |
